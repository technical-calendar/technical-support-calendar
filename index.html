Windows Desktop Application

Technical Support Calendar

기술지원 및 납품 일정 확인을 위한 Windows 데스크톱 애플리케이션입니다. 사용자가 선택한 Google Calendar의 일정을 읽고 당일 일정과 개인 관련 일정을 표시합니다.

주요 기능

  • Google 계정을 통한 캘린더 읽기 권한 연결
  • 공유 캘린더의 당일 일정 조회
  • 사용자 이름이 포함된 일정의 개별 알림
  • 육안 검수 및 NEXUS DB 입력 여부 확인 보조
  • Windows 로그인, 잠금 해제 및 절전 복귀 후 일정 확인 지원

Google Calendar 접근 범위

앱은 캘린더 일정을 읽기 전용으로 가져옵니다. 앱에서 일정을 클릭하면 Google Calendar 웹사이트를 열어 일정을 확인할 수 있습니다. 이 앱은 Google Calendar 일정을 직접 수정하거나 삭제하지 않습니다.

이용 및 문의

이 앱은 소규모 기술지원 팀의 업무 일정 확인을 위해 제작되었습니다. 문의는 프로젝트의 GitHub Issues를 통해 접수할 수 있습니다. 개인 정보나 인증 관련 비밀정보는 공개 이슈에 작성하지 마세요.
